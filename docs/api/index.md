# API

API рекомендательной системы учебных курсов предоставляет доступ к функциям подбора образовательных курсов на основе интересов студентов и ранее пройденных дисциплин.

С помощью API можно формировать персональные рекомендации, получать список рекомендованных курсов и просматривать подробную информацию о них.

## Основные операции

- `POST /recommendations` — сформировать персональные рекомендации учебных курсов на основе интересов студента и пройденных дисциплин;

- `GET /recommendations/{studentId}` — получить список рекомендованных курсов для конкретного студента;

- `GET /courses/{courseId}` — получить подробную информацию о выбранном учебном курсе.

## Формат данных

Для обмена данными используется формат JSON.

API возвращает результаты запросов и соответствующие HTTP-коды состояния.

## Спецификация

Полное описание API находится в файле [openapi.yaml](openapi.yaml).

Спецификация разработана в формате OpenAPI 3.0.3 и содержит описание endpoints, параметров запросов, успешных ответов и возможных ошибок.
