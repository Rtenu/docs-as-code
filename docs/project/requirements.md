## User Stories

### US-01. Указание интересов

Как студент,

я хочу указывать интересующие меня направления обучения,

чтобы получать рекомендации курсов в соответствии с моими интересами.

**Критерии приёмки:**

- студент может выбрать одно или несколько интересующих направлений;
- система сохраняет выбранные интересы;
- студент может изменить свои интересы.

### US-02. Учёт пройденных дисциплин

Как студент,

я хочу указывать ранее пройденные дисциплины,

чтобы система учитывала мои знания при подборе новых курсов.

**Критерии приёмки:**

- студент может выбрать пройденные дисциплины из списка;
- система сохраняет информацию о пройденных дисциплинах;
- студент может добавлять и удалять дисциплины из своего списка.

### US-03. Получение рекомендаций

Как студент,

я хочу получать персональные рекомендации учебных курсов,

чтобы выбирать наиболее подходящие курсы для дальнейшего обучения.

**Критерии приёмки:**

- система формирует рекомендации на основе интересов студента и пройденных дисциплин;
- студент видит список рекомендованных курсов с кратким описанием;
- если подходящих курсов нет, система выводит соответствующее сообщение.

## UC-01. Получение рекомендаций учебных курсов

**Актор:** студент.

**Цель:** получить персональные рекомендации учебных курсов на основе интересов и пройденных дисциплин.

**Предусловие:** студент указал свои интересы и ранее пройденные дисциплины.

**Основной сценарий:**

1. Студент открывает раздел «Рекомендации».
2. Система получает информацию об интересах студента и пройденных дисциплинах.
3. Рекомендательный алгоритм анализирует полученные данные.
4. Система формирует список подходящих учебных курсов.
5. Студент видит рекомендованные курсы с кратким описанием.
6. Студент выбирает интересующий курс для просмотра подробной информации.

**Альтернативный сценарий:**

Если система не находит подходящих курсов, она выводит соответствующее сообщение и предлагает студенту изменить свои интересы или дополнить список пройденных дисциплин.

**Результат:** студент получает список рекомендованных учебных курсов или уведомление об отсутствии подходящих вариантов.
