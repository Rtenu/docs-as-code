# Рекомендательная система учебных курсов

Сервис автоматически подбирает учебные курсы для студентов на основе их интересов, ранее изученных дисциплин и полученных знаний. Система анализирует предпочтения студента и предлагает наиболее подходящие курсы для дальнейшего обучения.

**Основные пользователи:**

- студент;
- администратор образовательной платформы.

**Основные функции:**

- указание учебных интересов и предпочтений;
- просмотр каталога доступных курсов;
- учет ранее пройденных дисциплин;
- формирование персональных рекомендаций;
- просмотр информации о рекомендованных курсах;
- добавление заинтересовавших курсов в избранное.


## Комплект документации

1. **Описание проекта** — предназначено для всех участников проекта и содержит общую информацию о назначении рекомендательной системы и её возможностях.

2. **Функциональные требования** — предназначены для разработчиков и определяют основные функции и ожидаемое поведение системы.

3. **Архитектура системы** — предназначена для разработчиков и описывает структуру системы, её компоненты и взаимодействие между ними.

4. **Документация API** — предназначена для разработчиков и описывает способы взаимодействия с системой через программные интерфейсы.

5. **Документация рекомендательного алгоритма** — предназначена для разработчиков и специалистов по машинному обучению, объясняет принципы подбора учебных курсов на основе интересов студента и пройденных дисциплин.

6. **Руководство пользователя** — предназначено для студентов и объясняет, как указывать интересы, просматривать рекомендации и выбирать учебные курсы.

7. **Руководство по установке и развертыванию** — предназначено для разработчиков и системных администраторов, содержит инструкции по установке, настройке и запуску системы.
