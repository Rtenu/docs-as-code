# Model Card

## Общая информация

**Название модели:**
intfloat/multilingual-e5-small

**Источник:**
https://huggingface.co/intfloat/multilingual-e5-small

**Автор / организация:**
intfloat. Авторы технического отчёта: Liang Wang, Nan Yang, Xiaolong Huang, Linjun Yang, Rangan Majumder, Furu Wei.

**Задача модели:**
Преобразование текстов в числовые векторы (эмбеддинги) для семантического поиска и определения смыслового сходства между текстами.

**Язык:**
Многоязычная модель, поддерживающая около 100 языков, включая русский и английский.

**Лицензия:**
MIT.

## Использование в проекте

Модель предполагается использовать в рекомендательной системе учебных курсов для сравнения интересов студента с описаниями доступных курсов.

При запросе `POST /recommendations` система получает интересы студента и список пройденных дисциплин.

На основе этих данных формируется текстовый запрос, который вместе с описаниями курсов передаётся модели.

Модель преобразует тексты в числовые векторы. Рекомендательный алгоритм сравнивает полученные векторы, определяет наиболее подходящие курсы и исключает ранее пройденные дисциплины.

Система возвращает студенту список рекомендаций с оценками соответствия через API.

## Входные данные

На вход модель получает текстовые данные:

- интересы студента;
- названия и описания пройденных дисциплин;
- названия и описания доступных учебных курсов.

Для поискового запроса используется префикс `query:`, а для описаний курсов — `passage:`.

## Выходные данные

Модель возвращает числовые векторы, отражающие смысловое содержание переданных текстов.

На их основе рекомендательный алгоритм рассчитывает степень сходства между интересами студента и учебными курсами.

Результатом работы всей системы является список рекомендованных курсов с оценками соответствия (`score`).

## Метрики качества

Авторы модели приводят результаты оценки на наборе данных Mr. TyDi.

Для multilingual-e5-small указаны следующие значения:

- средний MRR@10 — 64,4 по шкале от 0 до 100;
- MRR@10 для русского языка — 60,8.

MRR@10 оценивает качество ранжирования результатов поиска, учитывая позицию первого релевантного результата среди первых десяти.

Метрики качества рекомендаций именно учебных курсов авторами не указаны. Для нашего проекта потребуется отдельная оценка качества рекомендаций.

## Данные для обучения

Модель обучалась на нескольких многоязычных наборах текстовых данных.

Авторы указывают, в частности:

- mC4;
- CC News;
- Wikipedia;
- MIRACL;
- MS MARCO;
- Mr. TyDi.

Для дальнейшего описания датасета выбран MIRACL, использовавшийся при дообучении модели.

Источник:
https://huggingface.co/datasets/miracl/miracl

## Ограничения

**Ограничения, указанные авторами модели:**

1. Длинные тексты обрезаются до 512 токенов, поэтому часть информации может быть потеряна.

2. Качество модели может снижаться для языков с небольшим количеством обучающих данных.

3. Для корректной работы необходимо использовать префиксы `query:` и `passage:`. Их отсутствие может ухудшить результаты.

**Потенциальные ограничения для нашего проекта:**

1. Модель не обучалась специально для рекомендации учебных курсов, поэтому не всегда сможет правильно оценивать их соответствие интересам студентов.

2. Модель определяет смысловое сходство текстов, но самостоятельно не проверяет уровень подготовки студента и необходимые предварительные знания.

3. Качество рекомендаций зависит от полноты и точности описаний учебных курсов.

## Не рекомендуется использовать

Модель не рекомендуется использовать как единственный инструмент принятия решений об образовательной траектории студента.

Полученные рекомендации должны носить информационный характер и не ограничивать возможность самостоятельного выбора учебных курсов.

Также модель не следует использовать для автоматической оценки знаний, выставления оценок или принятия решений о допуске студентов к обучению.
