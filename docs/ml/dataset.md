# Data Sheet

## Общая информация

**Название датасета:**
MIRACL (Multilingual Information Retrieval Across a Continuum of Languages).

**Источник:**
https://huggingface.co/datasets/miracl/miracl

**Назначение:**
Датасет предназначен для обучения и оценки систем многоязычного информационного поиска.

Он позволяет оценивать способность моделей находить текстовые документы, соответствующие поисковым запросам пользователей.

**Лицензия:**
Apache 2.0.

## Состав данных

**Объём:**

Датасет содержит данные для 16 опубликованных языков, включая русский и английский.

Для русского языка представлены:

- 4 683 обучающих запроса;
- 33 921 оценка релевантности в обучающей выборке;
- 1 252 запроса в проверочной выборке;
- 13 100 оценок релевантности в проверочной выборке.

Отдельный корпус MIRACL для русского языка содержит 9 543 918 текстовых фрагментов.

**Тип данных:**

Текстовые данные: поисковые запросы, фрагменты статей Wikipedia и оценки их релевантности запросам.

**Основные поля / признаки:**

- `query_id` — уникальный идентификатор поискового запроса;
- `query` — текст поискового запроса;
- `positive_passages` — список релевантных текстовых фрагментов;
- `negative_passages` — список нерелевантных текстовых фрагментов;
- `docid` — идентификатор текстового фрагмента;
- `title` — название статьи;
- `text` — содержимое текстового фрагмента.

## Получение данных

Основой датасета послужили статьи Wikipedia на различных языках.

Поисковые запросы создавались носителями соответствующих языков. Они же оценивали релевантность текстовых фрагментов запросам.

Таким образом были сформированы пары «запрос — документ» с оценками соответствия.

## Предобработка

При подготовке текстового корпуса выполнялись следующие действия:

1. Из статей Wikipedia извлекалось текстовое содержимое.
2. Из данных исключались изображения, таблицы и другие нетекстовые элементы.
3. Статьи разделялись на отдельные текстовые фрагменты.
4. Для каждого фрагмента сохранялись идентификатор, заголовок статьи и текст.

Дополнительно авторы проводили автоматические и ручные проверки качества разметки.

## Ограничения

1. Датасет содержит преимущественно энциклопедические тексты, поэтому не отражает специфику описаний учебных курсов.

2. Объём данных отличается между языками, что потенциально может влиять на качество моделей для различных языковых групп.

3. Оценки релевантности создавались людьми и могут содержать субъективные различия.

4. Датасет предназначен для информационного поиска, а не непосредственно для персональных рекомендаций учебных курсов.

## Использование в проекте

MIRACL использовался при дообучении выбранной модели multilingual-e5-small.

В рекомендательной системе учебных курсов модель предполагается применять для определения смыслового сходства между интересами студента и описаниями курсов.

Датасет MIRACL может использоваться для оценки способности модели находить релевантные тексты.

Для полноценной проверки качества рекомендаций потребуется дополнительный набор данных с описаниями реальных учебных курсов и оценками их соответствия интересам студентов.
