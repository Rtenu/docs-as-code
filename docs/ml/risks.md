# Риски и ограничения

## Потенциальный bias

### Риск 1. Неравномерное распределение данных по языкам

**Риск:**

Существует потенциальный риск языкового смещения, поскольку объём обучающих данных для разных языков отличается.

**Возможное последствие:**

Качество рекомендаций может быть неодинаковым для студентов, использующих разные языки.

**Что можно сделать:**

Отдельно протестировать рекомендательную систему на русскоязычных и англоязычных текстах.

При необходимости дополнить данные примерами учебных курсов на языках, используемых студентами.

### Риск 2. Смещение в сторону определённых тематик

**Риск:**

Существует потенциальный риск тематического смещения, поскольку выбранная модель обучалась преимущественно на общих текстовых данных, а не на описаниях учебных курсов.

**Возможное последствие:**

Система может чаще рекомендовать курсы с привычной для модели терминологией и хуже определять соответствие узкоспециализированных дисциплин интересам студентов.

**Что можно сделать:**

Проверить качество рекомендаций на учебных курсах разных направлений.

При необходимости использовать дополнительный датасет, содержащий описания образовательных программ и дисциплин.

## Этические риски

### Риск 1. Обработка персональных данных студентов

**Риск:**

Рекомендательная система использует информацию об интересах студента и ранее пройденных дисциплинах.

**Возможное последствие:**

При недостаточной защите системы персональные данные могут стать доступны посторонним лицам.

**Способ снижения риска:**

Ограничить доступ к данным студентов, использовать защищённое хранение информации и обрабатывать только необходимые для формирования рекомендаций сведения.

### Риск 2. Чрезмерное доверие рекомендациям ИИ

**Риск:**

Студент может воспринимать рекомендации системы как гарантированно правильные.

**Возможное последствие:**

Студент может выбрать неподходящий курс, не учитывая собственный уровень подготовки или необходимые предварительные знания.

**Способ снижения риска:**

Указывать, что рекомендации формируются автоматически и носят информационный характер.

Предоставить студенту возможность самостоятельно изучать описания курсов и выбирать подходящие дисциплины.

## Вывод

Использование ML-модели позволяет автоматизировать подбор учебных курсов, однако не гарантирует абсолютную точность рекомендаций.

Для безопасного использования системы необходимо проверять качество рекомендаций, обеспечивать защиту данных студентов и сохранять возможность самостоятельного выбора учебных курсов.

Описанные потенциальные смещения требуют дополнительной проверки на данных образовательной платформы. Наличие таких смещений в выбранной модели для нашего проекта пока не установлено.
